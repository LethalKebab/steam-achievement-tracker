初始设置

只需要填一次,凭据存在本机的 config.json 里
① Steam Web API Key → steamcommunity.com/dev/apikey
② SteamID64 → steamid.io(把你的个人资料链接粘进去查)
③ 从表格导入(可选)
文件名里要含 RAW DATA / ACHIEVEMENTS / GUIDES 其中之一。 列按位置读,表头叫什么都行。
空模板: RAW DATA · ACHIEVEMENTS · GUIDES
④ Notion 攻略同步(可选)已配置
  1. 打开 notion.so/my-integrations,新建一个 Internal Integration,复制它的 secret
  2. 回到 Notion,打开放攻略的数据库(或它们的父页面)→ 右上角 ••• → Connections → 加上刚建的 integration。不做这一步会读不到页面。
  3. 把那个数据库当整页打开,地址栏里 ?v= 之前的 32 位十六进制就是数据库 ID
⑤ AI 攻略生成(可选)已配置
  1. 配好之后,Dashboard 上没有攻略的游戏会多出一个「✨ 生成」按钮,点了会联网查资料并写一份攻略
  2. 机器只保证格式和数据(每个成就一行、名字对得上、勾选等于真实解锁),攻略内容对不对没有任何东西能验,生成完自己读一遍

保存时会真发一次请求验证 —— key 无效、模型停售、这一档没额度,都只有发出去才知道。
