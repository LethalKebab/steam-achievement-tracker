第 1 步 · Steam必填

① Steam Web API Key → steamcommunity.com/dev/apikey
② SteamID64 → steamid.io(把你的个人资料链接粘进去查)

第 2 步 · AI 攻略生成可选已配置

给没有攻略的游戏联网查资料、写一份。内容准不准没法自动检查,生成完自己读一遍。

第 3 步 · Notion 攻略同步可选已配置

  1. 在 Notion 开发者页面 点 New connection,再从 Configuration 里复制 Access token
  2. 在 Notion 打开要放攻略的页面 → ••• → Add connections → 选中它
