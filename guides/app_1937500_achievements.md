# 学园构想家

appid: 1937500

## 一、开局与基础操作

- [x] **见习校长**<br>以任何一个难度开始生涯模式。<br>新建一个生涯存档就有,教程流程里自然到手。
- [x] **架构师**<br>拖动任意设施到管理部门下。<br>在设施管理界面把任意一个设施拖进「管理部门」分组即可,教程会教这个操作。
- [x] **重新装潢**<br>任意设施的星级达到2。<br>设施星级靠往房间里加装饰和配套设备堆。挑一间面积小的房间集中投入最快——大房间要填满同样的星级需要多得多的家具。

## 二、日常校务

- [x] **大演说家**<br>成功完成一次演讲。<br>演讲是校长的主动能力,对着聚集起来的学生使用。过程中有互动判定,搞砸了不会有惩罚,隔一段时间可以再来。
- [ ] **紧急止险**<br>成功灭火5次。<br>火灾大多来自用电密集和实验类的房间。要凑这五次,不必刻意制造事故——把消防设施配齐、让教师能及时赶到就行,一局下来自然会遇上几次。真想快点,可以暂时不修那些老是出问题的设备。
- [x] **满意答卷**<br>在一次考试中取得“优秀”的评级。<br>考试成绩看对应科目的教师水平、教室星级和学生状态三样。考前那几天别安排大型施工和活动,学生状态掉下去会直接反映在成绩上。
- [ ] **铁手腕**<br>派教师制止10次抗议。<br>抗议来自学生的不满累积——设施不够用、需求长期得不到满足都会引发。正常推进流程就会陆续遇到,不建议为了刷它故意压低满意度,那会连锁影响招生和考试。
- [x] **护苗行动**<br>没收30次违禁品。<br>靠教师巡查发现。安排两三名教师专职在学生活动区域走动,三十次会自己累积起来,不用专门管。
- [x] **水桶分配者**<br>罚站一名学生。<br>抓到违纪学生之后,在处理菜单里选罚站而不是其他处罚。

## 三、教师与职员

- [x] **自产自销**<br>进修一名教师。<br>进修要花钱、也要占用教师的时间,进修期间这个人不能上课。别在考试周或者教师本来就不够用的时候安排。
- [x] **精英人才**<br>成功招募一名精英教师。<br>精英教师在招聘列表里随机刷新,要价明显高于普通教师。前期看到不用勉强,签下来发不出工资更麻烦;等现金流稳定了再回头找。
- [x] **为人民服务**<br>使职员获得任一证书。<br>注意是**职员**不是教师——后勤、保洁这类非教学岗位同样能送去培训拿证,别在教师身上找。
- [x] **水到渠成**<br>给一名教师涨薪。<br>在教师详情里主动加薪,顺带能提升忠诚度,防止被别的学校挖走。

## 四、学生与招生

- [x] **难忘的记忆**<br>拍摄一张毕业照。<br>只有学年末的毕业环节能拍,看到提示别急着跳过。**不是永久错过**——这一届错过了,下一届毕业还能拍,只是要多等一个学年。
- [x] **大家庭**<br>学生人数达到100。<br>招生上限受教室和住宿容量限制,人数卡住多半是容量不够而不是没人来。先把硬件铺开再冲人数。
- [x] **广纳贤才**<br>招收20名3星志愿学生。<br>高星志愿学生和生源点的占有率挂钩,占有率低的时候来的多是低星。先把宣传投到一两个生源点上,别平均撒。
- [ ] **人才保送**<br>保送20名学生。<br>保送要求学生成绩达标,而且一次毕业只能出一批,二十名通常要跨两三个学年。想拿这个就要早点把教学质量做上去,拖到后期再补来不及。

## 五、建设与扩张

- [x] **房产达人**<br>购买一块新的空地。<br>在校园边界外选地块,资金够就能买下。
- [x] **耸入云宵**<br>在三层及以上的楼层建造。<br>要先解锁对应的楼层高度,然后在三层放任意建筑都算。
- [x] **初级建造师**<br>建设评分达到3000。<br>建设评分综合看建筑规模、星级和装饰。走建设路线的话这个是顺路的。
- [x] **建造大师**<br>建设评分达到8000。<br>比上一档高出一大截,基本要成规模的校园才够。和建设胜利是同一条路线,一起做。
- [x] **全日制**<br>建造男宿舍、女宿舍和宿舍大厅。<br>三样都要,缺一不可:
  - [ ] 男宿舍
  - [ ] 女宿舍
  - [ ] 宿舍大厅
- [x] **从天而降**<br>建造停机坪。<br>后期解锁的设施,对学园等级和资金都有要求,占地也不小,提前预留位置。
- [x] **奇观**<br>建造一个奇观。<br>造价和占地都是全游戏最高的一档。决定要造就提前空出整片区域,中途改地方等于白拆。

## 六、经济与运营

- [x] **见世面**<br>发现一块新的派遣区域。<br>派教师外出探索会解锁新的派遣区域。
- [x] **有借有还**<br>成功偿还一次贷款。<br>不用等到真缺钱。主动借一笔金额最小的贷款,手上有钱的时候立刻还掉就行。
- [x] **教育垄断家**<br>任一生源点占有率达到100%。<br>挑离学校最近、竞争学校最少的那个生源点集中投宣传。分散投的话哪个都到不了 100%。
- [x] **大富翁**<br>存款达到10,0000。<br>是十万,不是一百万——写法容易看岔。冲存款的时候先把在建的大工程停掉,不然钱一到账就被扣走。

## 七、研究与社团

- [x] **极致钻研**<br>完成所有研究。<br>研究要时间也要投入,尽早把研究设施建起来并安排固定的人,越晚开始越赶不完。
- [ ] **创立社团**<br>创立一个社团。<br>先建好社团活动场地,再到社团界面里创建。
- [ ] **区级第一**<br>任意社团排名达到区级第一。<br>集中资源培养**一个**社团,比几个社团平均发展快得多。
- [ ] **市级第一**<br>任意社团排名达到市级第一。<br>区级之后的下一档,同一个社团继续往上推。

## 八、人际关系

- [x] **情窦初开**<br>拥有成为恋人的学生或教师。<br>关系靠共同活动和相处时间累积,把两个人安排在同一片区域活动会快一些。
- [x] **挚友**<br>拥有成为挚友的学生或教师。<br>和上面同一套关系系统,挚友通常比恋人先达成,顺路就有了。

## 九、特殊事件

- [x] **邪恶校长**<br>拆除掉学生堆砌的雪人。<br>学生只在冬季才会在户外堆雪人,用拆除工具点掉即可。**不是永久错过**,但一年只有这一个窗口,过了就再等一年。
- [ ] **龙哥的“照顾”**<br>触发龙哥事件并接受。<br>随机事件。**必须选「接受」**才会解锁,选了拒绝这次就作废,要等下一次触发。
- [x] **井中精灵**<br>触发井中精灵事件。<br>随机事件,校园里得先有对应的水井设施才可能触发。

## 十、学园等级与通关

- [x] **区级学园**<br>学园等级达到5。<br>学园等级综合看规模、教学和声望,正常推进流程会到。
- [x] **顶级学园**<br>学园等级升至满级。<br>需要各项指标都拉满,是长线目标,基本要打到很后期。
- [x] **人数胜利**<br>达成人数胜利。<br>四种胜利之一,以学生规模为目标。走这条线要优先铺教室和宿舍容量。
- [x] **教学胜利**<br>达成教学胜利。<br>四种胜利之一,以教学成绩为目标。核心是教师质量和教室星级,别把钱都压在建筑上。
- [x] **建设胜利**<br>达成建设胜利。<br>四种胜利之一,以建设评分为目标,和「建造大师」是同一条路线。
- [ ] **社团胜利**<br>达成社团胜利。<br>四种胜利之一,以社团成就为目标,和「市级第一」同路。
- [x] **光辉生涯**<br>以困难模式通关一次游戏。<br>困难模式的资金和容错都更紧,建议先在普通难度熟悉一遍胜利条件的节奏,再开困难专门冲一条最熟的胜利线。
