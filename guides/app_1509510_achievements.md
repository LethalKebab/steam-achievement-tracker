- [x] **道路畅通**<br>单局内建造50格的路（沙盒模式无法完成）<br>规划城镇时铺设道路，木质路即可。每铺一格算一格，50格很容易达成。
- [x] **道路规划**<br>城镇中道路类建筑共计有2000格（沙盒模式无法完成）<br>这是一个累计数字。后期城镇壮大时，将主干道升级为石质路或更高级道路，并连接到每个建筑。多规划环形和分支路，积少成多。
- [x] **城镇建造**<br>单局中建造过所有桥梁和道路（包含隧道）（沙盒模式无法完成）<br>每个地图可建造的桥梁和隧道种类有限。需要在对的地图、对的位置才能解锁建造选项。需要规划城市在河边和山边发展，把所有可解锁的桥梁都造一遍，并注意隧道口方向。该成就与地图资源强相关，建议专门开一局建造。
- [x] **建筑工**<br>保持十年没有建筑损坏（沙盒模式无法完成）<br>建筑会因年久失修或灾难（如暴风雪、龙卷风）而损坏。需要保证建筑材料充足并让工人持续维修。提升建筑等级有助于减少损坏频率。十年间需避开重大灾害。
- [x] **建筑师**<br>建造40种不同类型的建筑（沙盒模式无法完成）<br>随着人口与科技发展逐步解锁蓝图，住宅、生产、加工、服务、市政等类别加起来很容易达到。保持科技发展与人口规模增长即可。

- [x] **温暖住所**<br>人口100以上时，所有市民都居住在奢华住宅或花园别墅中（沙盒模式无法完成）<br>奢华住宅和花园别墅是高级住宅，需要解锁科技并使用奢侈品、玻璃等材料建造。人口超过100后，需要拆除旧房原地重建，并注意住房等级与市民幸福感。最好在人口刚过100时评估住房情况，避免人口继续增长后难以满足条件。
- [x] **大城堡**<br>所有市民居住在大城堡中（沙盒模式无法完成）<br>大城堡是蓝图中的最终住宅之一，容量较大。需要先将一个住宅建筑改建为“大城堡”，然后保证人口不超过其容量上限。建议将人口控制在城堡容量内。该成就需专门规划，因为大城堡建造昂贵且缓慢。

## 商业与贸易

- [x] **连续订购**<br>单局中订购十次（沙盒模式无法完成）<br>在贸易站中下单订购货物。连续订购可能指在连续的几次贸易刷新中都有订购行为，或累计十次，可按累计十次来规划。留意贸易事件刷新时间。
- [x] **动物进口**<br>购买两种动物（沙盒模式无法完成）<br>贸易站可以购买动物，如牛、羊、鸡等。前提是建造了相应的牧场蓝图。在贸易站切换货物列表至“动物”分类，即可购买。两种动物即可，尽早购买并饲养，还可以帮助其他相关成就。
- [x] **经济发达**<br>获得银币1000000（沙盒模式无法完成）<br>银币主要通过税收、贸易获得。需要维持大量的人口和繁荣的经济。大后期贸易利润是核心，通过高附加值商品（如礼服、工具）换取大量银币。累计获得而非持有，可以放心消费。也可在贸易站大量出售稀缺物资。
- [x] **经商头脑**<br>任意势力声望达到5级（沙盒模式无法完成）<br>通过贸易站与势力交易，每次交易提升声望。优先与单一势力大量交易，并完成该势力委托的任务（如果有）。需要持续贸易，高价值货物可以更快提升声望。
- [x] **名震四方**<br>李妙、洛伦佐、拉尼娅、卡洛斯的势力声望均达到5级（沙盒模式无法完成）<br>四个势力都需要提升到5级，需要同时与四方大量交易。贸易站中留意四位势力代表——李妙、洛伦佐、拉尼娅、卡洛斯。这是一个长期目标，需要规划不同货物的生产以应对不同势力的需求。

## 人口、教育与幸福度

- [x] **繁衍生息**<br>连续十年维持人口在100以上（沙盒模式无法完成）<br>保证市民有住所、食物、燃料和一定的幸福度，人口会自然增长。注意避免在十年期间出现重大灾难。住房容量需要超过100，人口过低时可能需要主动吸引移民或接纳流民。
- [x] **维持幸福**<br>连续十年维持城镇幸福度在60%以上（沙盒模式无法完成）<br>幸福度由衣食住行、娱乐、宗教、环境等多因素构成。保证多样化的食物、衣物、住房等级，并建造教堂、酒馆等娱乐设施。关注压力值，压力过高会拉低幸福。
- [x] **身体健康**<br>连续五年健康度超过100%（沙盒模式无法完成）<br>健康度超过100%表示市民处于非常健康的状态。需要多样化食物、干净的水源（水井）、医院/诊所提供医疗服务，并控制污染。健康度超过100%并非难事，但需保持五年。
- [x] **心情愉悦**<br>连续五年幸福度超过100%（沙盒模式无法完成）<br>幸福度超过100%需要极高的生活水平，不仅要满足基本需求，还要提供奢侈品、高级娱乐、宗教活动、低压力。检查各项幸福度加成，缺什么补什么。
- [x] **悠然自得**<br>500人口以上保持五年总压力低于20（沙盒模式无法完成）<br>总压力是城镇整体压力的总和，等于市民压力值相加。当人口达到500时，保证每个人的压力都极低极为困难。重点在于提供足够的娱乐设施、教堂、降低工作强度（充足人手）、保证食物多样。这可能需要将工作场所全部满员，并为市民提供度假/休养选项。五年时长对持续运营要求很高。
- [x] **治疗瘟疫**<br>经历一次瘟疫没有市民因为瘟疫死亡（沙盒模式无法完成）<br>瘟疫触发后，需要第一时间建造医院并配置医生。隔离病患，加强卫生设施（澡堂、垃圾站）。暂停人口流动（如果可能）。重要的是反应速度，瘟疫蔓延非常快。
- [x] **救死扶伤**<br>累计治疗500个病人（沙盒模式无法完成）<br>建造医院并配置医生后，市民生病时会自动前往治疗。城市人口越多、卫生条件越差，病人越多。可以通过降低卫生设施投入来“制造”病人，同时保证医院运力。累计数字，长期游戏即可达成。
- [x] **文明之地**<br>单局累计毕业200学生（沙盒模式无法完成）<br>建立学校并保证儿童入学。学校需要一名教师。随着人口增长，毕业生会更多。累计数字，中后期很容易达成。
- [x] **博览群书**<br>消耗1000书籍（沙盒模式无法完成）<br>书籍在印刷工坊或类似建筑中生产，市民通过图书馆消耗书籍提升心情和知识。建造图书馆并保持书籍供应，消耗速度与图书馆数量和访问量相关。
- [x] **学无止境**<br>超过三百人口后，保证十年内所有成年人受教育率100%（沙盒模式无法完成）<br>受教育率指所有成年人都经历过学校教育。保证人口在300人以下时学校覆盖率足够，使每个儿童都能入学。一旦超过300人，十年内维持所有成年人都是“受教育”状态，即在此期间不能有未受教育的成年移民或流民加入。需要在10年内严格控制人口流入，避免接受流民或主动吸引移民，同时保证现有成年人不死亡或离开。

## 科技与研究

- [x] **熟练工人**<br>单局累计消耗工具500件（沙盒模式无法完成）<br>工具是生产建筑的耐用消耗品。建造更多使用工具的作坊和工厂，如伐木场、矿场、裁缝铺等。几乎整个游戏都在消耗工具，累计消耗500件是必然成就，但可以加速，例如多开箱子、捕猎等岗位。
- [x] **科技强化**<br>在标准模式中解锁一个三级科技<br>科技树有等级，需要大量科研点数。在科研所安排科学家，并保证大学的运行，即可逐步解锁。
- [x] **科技城镇**<br>在标准模式中解锁所有科技<br>需要将所有科技分支研究完毕，科研点数总消耗极大。需要持续保证研究机构运转和人口教育水平，大后期才能完成。需要先达成“学无止境”或“博览群书”这类教育成就。
- [ ] **全面发展**<br>30年之前，科技等级达到100级（沙盒模式无法完成）<br>科技等级是科技树的总等级（可能指科技点总等级或科技树等级总和）。需要非常早地建立科研所并安排多个科学家。前三十年是黄金期，需要集中资源冲刺科研，同时维持城镇基本运转。建议开局就规划大规模教育体系。

## 市政与杂项

- [x] **城市管理者**<br>续任一次管理者（沙盒模式无法完成）<br>管理者任期结束时会触发连任事件，可能是自动连任或需要满足一定条件（如幸福度达标）。注意可能出现的“换届”选项。通常意味着你需要在该局游戏中游玩足够长时间。
- [x] **满负荷**<br>拥有至少10个加工建筑且所有加工建筑的工作人数达到上限（没有空余职位）（沙盒模式无法完成）<br>加工建筑如磨坊、裁缝铺、铁匠铺、木工坊等。需要至少建立10个，并给每个建筑满编工人。缺人时需要吸引移民或等待新生儿成长。注意“没有空余职位”指的是这10个建筑没有空缺，但城镇其他地方可以有。
- [x] **水力设施**<br>建造好所有水力加工建筑（沙盒模式无法完成）<br>水力加工建筑建在水车旁，如水力磨坊、水力锯木厂等。需要寻找地图上的水源河流，在合适位置建造。不同水车供应的建筑可能不同，需要解锁全部蓝图。
- [x] **矿产丰富**<br>建造一座深层矿井和一座深层采石场（沙盒模式无法完成）<br>深层矿井和深层采石场是矿物的后期来源，需要先建造普通的矿井和采石场，再升级为深层。需要大量石料、木材和铁。
- [x] **珍稀资源**<br>累计产出10000玉石和金沙（沙盒模式无法完成）<br>玉石和金沙由深层矿井和深层采石场开采，属于稀有资源。达到此产量需要长时间的深层采集，可能需要多个深层建筑同时运作。
- [x] **大清理**<br>清理掉地图上所有石矿和铁矿（沙盒模式无法完成）<br>地图上的石矿和铁矿是有限的露天矿点。需要派工人将所有矿点采空。可提前在暂停模式下探索地图，标记所有矿点。采空后不会再生成，同时也要注意不要漏掉角落里的矿点。
- [x] **抵御严寒**<br>连续十年冬天没有市民因为寒冷死亡（沙盒模式无法完成）<br>保证冬季供暖充足。除了燃料外，住房等级和衣物等级也非常关键。检查在暴雪年或寒潮年是否有供暖缺口。提前储备大量燃料，并升级住房保暖等级。
- [x] **暴风雪**<br>经历一次暴风雪，且没有人冻死（沙盒模式无法完成）<br>暴风雪是随机灾难，应对方法与“抵御严寒”类似，但暴风雪期间温度更低。预警出现时需立刻调配燃料分配，并暂停野外作业。医院能治疗冻伤，减少死亡。
- [x] **饱经风雪**<br>火灾/暴风雪/龙卷风/干旱/动物瘟疫/丰收/沙尘暴/洪涝/地震都经历一次（沙盒模式无法完成）<br>这是一个灾难收集成就。多数灾难随机触发，可以建造对应防灾设施（消防站、防洪堤等）来降低损失，但为了成就可能需要故意不建来触发灾难。丰收事件可能不是灾难，而是好事。推荐在后期放松警惕，多建易燃建筑增加火灾概率。
- [x] **摸鱼为王**<br>触发摸鱼勇者所有负面效果（沙盒模式无法完成）<br>“摸鱼勇者”通常是城镇中某个 NPC 或随机事件的特定结果，需要特定的职业或建筑配置。需要触发该事件并根据选项走向不同的负面结局。不同负面效果都要触发一次，可能需要在多次游戏中完成。留意游戏内的随机事件选择。
- [x] **神庙祭祀**<br>建造出大神庙（沙盒模式无法完成）<br>大神庙是宗教建筑的最终形态，需要满足人口、宗教热情等条件解锁。需要大量石料和宝石等材料。建造时间可能极长，需提前准备资源。
- [x] **城市中心**<br>建造一座市政厅（沙盒模式无法完成）<br>市政厅是一个关键建筑，通常要求人口达到一定数量才能建造。对科技和材料有一定要求。可以尽早规划。
- [x] **海纳百川**<br>接纳五次流民（沙盒模式无法完成）<br>流民会在游戏进程中随机到达城镇边缘，点击城镇入口或相关提示选择接纳。需要保持城市有足够食物和住房，否则接纳后可能崩溃。五次接纳可以跨多年，但一次游戏中通常会出现多次流民事件。
- [x] **嗜酒如命**<br>累计消耗1000酒类（沙盒模式无法完成）<br>酒类通过酿酒坊生产，市民在酒馆消耗。需要建立酒馆并提供持续的酒类供应。累计消耗1000需要很长时间，中后期需求量才会增加。保持酒馆运营并扩大酒类产量即可。
