# 部落幸存者

## 开局与基础建设

- [x] **基础设施**<br>开局一年内建造好裁缝铺，铁匠铺，劈柴小屋（沙盒模式无法完成）<br>开局就把这三样列为第一优先级,先攒够木头和石材:劈柴小屋最便宜先建,铁匠铺需要铁矿(地图上先派采集),裁缝铺需要皮革(尽快开狩猎)。第一年结束前建齐,别把建材全投进农田和住房。
- [x] **道路畅通**<br>单局内建造50格的路（沙盒模式无法完成）<br>开局铺路就顺手解锁,住宅区、工作区之间拉几条路即可,不用刻意规划。
- [x] **城市中心**<br>建造一座市政厅（沙盒模式无法完成）<br>中前期攒够建材建一座市政厅,顺带开启管理者选举机制,和"城市管理者"成就一起做。
- [x] **农业大亨**<br>在一年内，种植并收获三种不同的农田作物（沙盒模式无法完成）<br>开局别把所有农田种同一种作物,小麦、卷心菜、南瓜等分三块田,春天播种秋天收获,一年内就跳成就。
- [x] **熟练工人**<br>单局累计消耗工具500件（沙盒模式无法完成）<br>工具在采矿、伐木、建筑等环节持续消耗,正常发展自动解锁,不用刻意刷。
- [x] **建筑工**<br>保持十年没有建筑损坏（沙盒模式无法完成）<br>后期科技点出"改造:结构强化"后给主要建筑加固,灾害(尤其地震、龙卷风)是主要破功来源。存个档,把全城加固完挂十年即可。

## 人口与民生

- [x] **繁衍生息**<br>连续十年维持人口在100以上（沙盒模式无法完成）<br>保证食物、住房、医疗充足,人口过百后保持十年。别在这期间大规模拆住房或断粮。
- [x] **抵御严寒**<br>连续十年冬天没有市民因为寒冷死亡（沙盒模式无法完成）<br>冬天前备足保暖衣物(裁缝铺产)和燃料,住宅供暖跟上;寒冷死亡率高的是老人和病人,入冬前保证诊所和食物供给。
- [x] **维持幸福**<br>连续十年维持城镇幸福度在60%以上（沙盒模式无法完成）<br>教堂、剧院、酒馆、多样化食物、好衣服都能拉幸福度,60%不难维持。注意别大规模爆人口导致幸福被摊薄。
- [x] **治疗瘟疫**<br>经历一次瘟疫没有市民因为瘟疫死亡（沙盒模式无法完成）<br>瘟疫大多由流民带入。平时备足药粉/特效药、诊所医生在岗;法令里开"强身健体"可降低50%患病率。爆发时确保药物供应不断,病人能及时进诊所就不会死人。
- [x] **暴风雪**<br>经历一次暴风雪，且没有人冻死（沙盒模式无法完成）<br>暴风雪要靠等。开新档把"温差"调成剧烈更容易触发,挂机等事件即可。想取巧的话可以先把市民全饿/冻死再等暴风雪——没有活人就不会有人冻死,一样算达成。
- [x] **身体健康**<br>连续五年健康度超过100%（沙盒模式无法完成）<br>药粉、医院、多样化食物、保暖、低压力都能拉健康。幸福度高了健康通常也跟着上去,和"心情愉悦"一起做。
- [x] **心情愉悦**<br>连续五年幸福度超过100%（沙盒模式无法完成）<br>后期造出大神庙能献祭市民+30%幸福度,配合教堂、剧院、美食、奢华服饰把幸福度顶过100%挂五年。大神庙优先献祭老人,老人多了幸福度反而好控。
- [x] **悠然自得**<br>500人口以上保持五年总压力低于20（沙盒模式无法完成）<br>后期大城挂机成就。压力来自工作强度、寒冷、疾病、缺酒缺娱乐;吃好穿好、酒馆剧院管够、劳动强度别拉满。人口破500后保持低压力五年。
- [x] **救死扶伤**<br>累计治疗500个病人（沙盒模式无法完成）<br>诊所/医院保持医生在岗,市民生病能及时就诊即可累计。爆瘟疫时治疗量涨得飞快。
- [x] **嗜酒如命**<br>累计消耗1000酒类（沙盒模式无法完成）<br>造酿酒坊产酒、酒馆让市民喝,累计消耗1000份酒类。酒还能拉幸福和减压,属于民生刚需。
- [x] **海纳百川**<br>接纳五次流民（沙盒模式无法完成）<br>流民事件弹窗时选接纳,累计五次。前期流民带来人口也带来瘟疫风险,注意备药。
- [x] **温暖住所**<br>人口100以上时，所有市民都居住在奢华住宅或花园别墅中（沙盒模式无法完成）<br>后期把全城住房统一升级/替换成奢华住宅或花园别墅,确保人口100以上时没人住在其他房子里。资源紧张就存个档,建好后等成就跳了再回档。

## 生产与资源

- [x] **美味食物**<br>在一年内产出10000的简单食物（沙盒模式无法完成）<br>简单食物包括农田产出和磨坊/厨房加工品。后期多开农田、把农场职工拉满,再配磨坊加工,一年产出破万并不难。
- [x] **种植大户**<br>单局获得所有种子（沙盒模式无法完成）<br>种子靠商船、贸易获取,流民和市长也可能给。打开"城市详细"能看到自己缺哪几样,盯着商船补货即可。
- [x] **动物进口**<br>购买两种动物（沙盒模式无法完成）<br>商船到港时买两种动物(牛、羊、鸡等),攒够钱一次买齐即可。
- [x] **奢华服饰**<br>一年产出100个定制礼服（沙盒模式无法完成）<br>定制礼服吃高级材料(丝绸等)。先攒够材料,再一次性多建几座服装厂把产能顶上去,产完100件就拆掉,避免长期占人手。
- [x] **高效工具**<br>200个成年人并且都持有钢制工具（沙盒模式无法完成）<br>先让成年人口过200,铁匠铺产够钢制工具让每个成年人都配上一把。注意工具会被消耗,保持产量覆盖损耗。
- [x] **手推车**<br>100个成年人并且都持有手推车（沙盒模式无法完成）<br>生产手推车并保证100个成年人各持一辆,手推车提升搬运效率,产量覆盖住损耗即可。
- [x] **满负荷**<br>拥有至少10个加工建筑且所有加工建筑的工作人数达到上限（没有空余职位）（沙盒模式无法完成）<br>只要凑够10个加工建筑并把职位全部填满。注意有些建筑默认职位不满,比如编织小屋建出来默认1人,要手动加到2人才算满。按快捷键4可以高亮加工类建筑,在"城市详细-加工"里对照检查空缺职位。
- [x] **水力设施**<br>建造好所有水力加工建筑（沙盒模式无法完成）<br>水力加工建筑(水车磨坊、水力锯木厂等)要建在河边/水流旁。对照蓝图把每种水力加工建筑各建一座,地图选水源充足的开局更省事。
- [x] **矿产丰富**<br>建造一座深层矿井和一座深层采石场（沙盒模式无法完成）<br>科技解锁后各建一座,深层矿井/深层采石场不依赖地表矿脉,属于后期无限产出建筑。
- [x] **珍稀资源**<br>累计产出10000玉石和金沙（沙盒模式无法完成）<br>金沙和玉石分别由砂、石按10:1加工而来,产出极慢。后期多建淘金小屋和玉石工坊,职工拉满,再从码头大量购入砂和石喂给它们。按累计产出算不是看库存,挂机开10倍速等上几个游戏十年很正常。
- [x] **大清理**<br>清理掉地图上所有石矿和铁矿（沙盒模式无法完成）<br>把全图所有地表石矿和铁矿采空。山体不算在成就内,但可能挡住藏在后面的矿,记得绕山排查。小地图更容易清干净;漏了可以用存档读档配合"城市详细"逐个找。

## 科技与教育

- [x] **科技强化**<br>在标准模式中解锁一个三级科技<br>标准模式中期正常点科技树就解锁,三级科技需要前面两级点满。
- [x] **科技城镇**<br>在标准模式中解锁所有科技<br>大后期成就,需要大量研究点和书籍/纸张支持,是"全面发展"的延伸目标。
- [x] **文明之地**<br>单局累计毕业200学生<br>多建学校、保证教师充足,学生毕业累计到200。后期人口多时自然达成。
- [x] **博览群书**<br>消耗1000书籍<br>研究院/学院做研究会消耗书籍,研究科技和"全面发展"的过程中顺手达成。
- [x] **学无止境**<br>超过三百人口后，保证十年内所有成年人受教育率100%（沙盒模式无法完成）<br>受教育率连孩子一起算,所以学校容量和教师必须覆盖所有适龄儿童,别漏建学校。最省事的做法:拉尼娅势力声望到5级解锁"大学院",建一座让成年人都进学院挂着,十年后就达成,不建议靠堆小学来做。
- [x] **熟能生巧**<br>某项熟练度等级达到三级（沙盒模式无法完成）<br>同一批市民长期干同一工种,熟练度会慢慢涨。选定一个工种(如采矿)让人口不换岗,挂几十年即可;市长提供的熟练度加成也能推一把。
- [ ] **全面发展**<br>30年之前，科技等级达到100级（沙盒模式无法完成）<br>全程限时最难成就之一,建议单独开档专攻:前十年保证食物衣物燃料充足,把李妙势力升到一级并种上竹子;中期开始全力堆造纸(蔡伦造纸厂)和研究所,造纸厂职工拉满——注意加工配方默认用木头,一定要改成竹子/纸的配方;造纸比造书便宜,前期用纸喂研究所就够了。蓄水池要多建(十来个起),职工拉满,法令点"净水技术"+25%产量。研究所数量越多越好,挂机等第30年结算。注意:成就按30年结束时的科技等级判定,提前到100级也要等年份走完。

## 贸易与经济

- [x] **经商头脑**<br>任意势力声望达到5级（沙盒模式无法完成）<br>和势力交易,买卖金额都涨声望。随便挑一家(李妙或卡洛斯)多倒几轮就能到5级,是"名震四方"的前置。
- [x] **名震四方**<br>李妙、洛伦佐、拉尼娅、卡洛斯的势力声望均达到5级（沙盒模式无法完成）<br>四个势力全刷到5级,最花时间的成就之一,同时会解锁各势力的专属蓝图(洛伦佐5级给大城堡、卡洛斯5级给大神庙、拉尼娅5级给大学院)。靠贸易流:交易金额无论买卖都涨声望,利用势力间商品差价倒买倒卖可以一边赚钱一边刷;粗略路线是食物类从李妙低价买入、高价卖给拉尼娅/卡洛斯,服装类李妙买入卡洛斯卖出,贸易品类拉尼娅买入卡洛斯卖出。稻草人这类高单价贸易品单次涨声望最多。

  - [ ] 洛伦佐声望5级
  - [ ] 拉尼娅声望5级
  - [ ] 卡洛斯声望5级
- [x] **连续订购**<br>单局中订购十次（沙盒模式无法完成）<br>码头有"订购"功能,和普通交易分开,每隔一年才能用一次,买最便宜的东西也算一次。前期费用偏高,后期有钱了随便订满十次。
- [x] **经济发达**<br>获得银币1000000（沙盒模式无法完成）<br>累计获得100万银币,靠倒买倒卖和后期工业品出口。想加速可以造"摸鱼勇者"赌随机事件,赌到99999银币就关掉建筑,注意摸鱼勇者无法存档读档。

## 建筑与城镇

- [x] **建筑师**<br>建造40种不同类型的建筑（沙盒模式无法完成）<br>正常玩到后期,住宅、生产、加工、市政、娱乐各种建筑凑够40种,不用刻意刷。
- [x] **建筑专家**<br>解锁所有蓝图（沙盒模式无法完成）<br>蓝图随机刷在商船上,是著名的看脸成就。老办法:商船到港前存档,到港后没刷出需要的蓝图就回档重来,可能需要几十次。装了旅游DLC的话可以用旅游点数直接买蓝图,省去大量SL。在"城市详细"里可以查还缺哪些蓝图。
- [x] **住房改造**<br>拥有50个永不磨损的住房（居住的场所）（沙盒模式无法完成）<br>科技点出"改造:结构强化"后,点开任意住房右上角的强化,选"加固",显示不可摧毁就算成功。给50座住房都加上,顺带让地震也拆不掉它们。
- [x] **大城堡**<br>所有市民居住在大城堡中（沙盒模式无法完成）<br>洛伦佐势力声望5级解锁大城堡蓝图。每座大城堡要9999砖、9999硬木外加数千建筑套件,造价和工期都极其夸张。做成就时先存档,只建一座大城堡并关停/拆除其他所有住宅,等市民全部搬进去跳成就后回档。
- [x] **道路规划**<br>城镇中道路类建筑共计有2000格（沙盒模式无法完成）<br>把全城路网铺开,或者绕地图外围拉一圈长路,累计2000格。后期铺路材料充足时顺手做。
- [x] **城镇建造**<br>单局中建造过所有桥梁和道路（包含隧道）（沙盒模式无法完成）<br>把每种路面、每种桥梁和隧道都建过一次。对照蓝图逐项补,容易漏的是隧道和特殊材质路面。
- [x] **高效供暖**<br>连续二十年不消耗生活燃料（沙盒模式无法完成）<br>建锅炉房集中供暖,让所有住宅都纳入锅炉房范围——住宅在范围内就不会自己烧柴火。法令"集中供暖"能+30%锅炉房范围,住宅面板左侧可以查看是否在供暖范围内。锅炉烧煤,二十年不烧柴就能跳。
- [x] **神庙祭祀**<br>建造出大神庙（沙盒模式无法完成）<br>卡洛斯势力声望5级解锁大神庙蓝图,材料到位后建出来即可。大神庙献祭市民换+30%幸福度,还优先献祭老人,对"心情愉悦"和老人过多的人口结构都有奇效。
- [x] **城市管理者**<br>续任一次管理者（沙盒模式无法完成）<br>市政厅建好后选出一位管理者,任期结束后在选举界面续任同一个人,一次就跳。挂着让任期自然走完即可。
