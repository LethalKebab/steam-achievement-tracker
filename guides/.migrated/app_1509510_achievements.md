## 开档前速查

- **模式**:以下成就绝大多数标注"沙盒模式无法完成",全成就请用标准模式开新档。建议开一局长线档把所有时间型成就放在同一局做,开局资源拉满、难度调低能省很多事。
- **势力声望**:李妙、洛伦佐、拉尼娅、卡洛斯四家势力,声望通过商船贸易和完成势力订单提升;每家到5级各解锁一张关键蓝图(洛伦佐→大城堡、拉尼娅→大学院、卡洛斯→大神庙),是名震四方、建筑专家、大城堡、学无止境、神庙祭祀的前置。
- **特殊建筑**:开局创建时勾选"特殊建筑",摸鱼勇者蓝图每半年解锁一次,是摸鱼为王成就的来源。
- **天灾**:科技"结构强化"可让建筑免于地震、龙卷风摧毁;蓄洪水库缩短洪涝;法令"集中供暖"给锅炉房+30%范围。这些是饱经风雪、建筑工、高效供暖的共同帮手。

## 生存与人口

- [x] **繁衍生息**<br>连续十年维持人口在100以上（沙盒模式无法完成）<br>中期城镇稳定后自然达成。核心是食物、住房、供暖不缺,人口过100后别大规模拆住房或断粮。
- [x] **维持幸福**<br>连续十年维持城镇幸福度在60%以上（沙盒模式无法完成）<br>稳定供给食物、酒和衣物,教堂与剧院覆盖住宅区,幸福度轻松过60%。注意别长时间缺酒缺药导致幸福度滑坡。
- [x] **抵御严寒**<br>连续十年冬天没有市民因为寒冷死亡（沙盒模式无法完成）<br>保证燃料供应充足,冬天前备好厚衣物,后期用锅炉房集中供暖,十年无冻死。
- [x] **治疗瘟疫**<br>经历一次瘟疫没有市民因为瘟疫死亡（沙盒模式无法完成）<br>瘟疫多由流民带入。平时备足药粉/特效药,法令开"强身健体"可减50%患病率;瘟疫爆发时诊所满员、药物不断供即可扛过。
- [x] **救死扶伤**<br>累计治疗500个病人（沙盒模式无法完成）<br>多造诊所并保证草药、药粉供应,病人会自动就医。长局里伤病、瘟疫自然累计,500人只是时间问题。
- [x] **身体健康**<br>连续五年健康度超过100%（沙盒模式无法完成）<br>健康度过100%需要持续药物供给和诊所覆盖。把草药种植和药物加工做起来,配合"强身健体"法令,五年轻松保持。
- [x] **心情愉悦**<br>连续五年幸福度超过100%（沙盒模式无法完成）<br>幸福度要过100%得把食物种类、酒、衣物、教堂、剧院全部拉满;后期大神庙献祭可+30%幸福度,是冲100%的关键助力。
- [x] **嗜酒如命**<br>累计消耗1000酒类（沙盒模式无法完成）<br>酒是维持幸福度最廉价的消耗品。种龙舌兰→酿酒坊量产烈酒,500人口以上的城镇一年能喝掉几百,1000是自然积累。
- [x] **海纳百川**<br>接纳五次流民（沙盒模式无法完成）<br>流民事件定期出现,缺人时点接纳即可。流民可能带病,接纳前先保证诊所和药物储备。
- [x] **悠然自得**<br>500人口以上保持五年总压力低于20（沙盒模式无法完成）<br>压力要压到20以下,住房是主力:全部换成花园别墅/奢华住宅(各减25/15压);蓝图里的石狮子和石中剑各建一座,各减25%压力(最多减50%);再配合食物酒水、教堂剧院把幸福和健康拉满。500人口以上保持五年即跳。

## 生产与加工

- [x] **农业大亨**<br>在一年内，种植并收获三种不同的农田作物（沙盒模式无法完成）<br>开局铺几块不同作物的田(小麦、玉米、土豆等),同一自然年内全部收获即可。
- [x] **美味食物**<br>在一年内产出10000的简单食物（沙盒模式无法完成）<br>简单食物靠农田+磨坊加工。准备5-8块大田种高产粮食作物,收获季全员下田、磨坊不停工,一年产出破万不难。前期人力不够别急着做,后期顺手达成。
- [x] **种植大户**<br>单局获得所有种子（沙盒模式无法完成）<br>种子来源:清理资源随机挖到、商船随机出售、势力商店购买。打开城市详细面板能看到还缺哪些种子,定向等商船刷;商船到达前存档,没出想要的种子就回档。后期把所有作物各轮一遍基本就齐了。
- [x] **奢华服饰**<br>一年产出100个定制礼服（沙盒模式无法完成）<br>定制礼服是后期服装产品。攒够布料等材料库存,一次性多建几座服装厂同时开工,凑满100件后拆掉即可,不必长期维持。
- [x] **熟练工人**<br>单局累计消耗工具500件（沙盒模式无法完成）<br>工具会随使用磨损消耗,铁匠铺持续产石/铁工具,玩到中期自然累计500件。
- [x] **高效工具**<br>200个成年人并且都持有钢制工具（沙盒模式无法完成）<br>先让成年人过200,再保证钢制工具库存充足,工人会自动领取更高级的工具。钢制工具需解锁钢铁加工科技并建锻造厂量产。
- [x] **手推车**<br>100个成年人并且都持有手推车（沙盒模式无法完成）<br>手推车在工具类建筑生产,属消耗品。人口过100后保证不断供,工人领到即计入。做高效工具时顺手一起做。
- [x] **矿产丰富**<br>建造一座深层矿井和一座深层采石场（沙盒模式无法完成）<br>矿业科技线点到底,各建一座深层矿井(矿)和深层采石场(石)即可。深层建筑吃资源人力,后期再造。
- [x] **珍稀资源**<br>累计产出10000玉石和金沙（沙盒模式无法完成）<br>位置 地图上有玉石和金沙标志的矿点。把矿井/采石场建在对应标志上即可产出。这是长线硬成就:矿点多开、满员运行;商船和势力贸易买到的玉石金沙也计入累计,能买就买。放在做经济发达(卖雕像)的同一局顺手完成,别单独开档。
- [x] **大清理**<br>清理掉地图上所有石矿和铁矿（沙盒模式无法完成）<br>位置 全图所有石矿、铁矿点。把地图上所有石矿和铁矿都开采到枯竭。开图时规划好哪些矿点留到中期用,最后期人力充裕时把所有矿点同时开满、派人挖到消失。属于大后期收尾成就,和珍稀资源、经济发达放同一局做。
- [x] **满负荷**<br>拥有至少10个加工建筑且所有加工建筑的工作人数达到上限（没有空余职位）（沙盒模式无法完成）<br>造10座加工建筑并全部满员。注意有些建筑的职位可以手动加(如编织小屋默认1人,要加到2),按快捷键4查看加工类建筑,再打开城市详细→加工,把每个空余职位补上。

## 科技与教育

- [x] **科技强化**<br>在标准模式中解锁一个三级科技<br>科技树第三级科技(如研究所、印刷术这类)点出一个即可。教育线往上点,很快就有三级可点。

- [ ] **全面发展**<br>30年之前，科技等级达到100级（沙盒模式无法完成）<br>科技等级=累计获得的科技点。开局资源拉满、难度调低,前十年先稳住生活物资并铺几所学校,点出印刷术等教育科技后立刻大量建造研究所并满员运行,15年左右开始爆发,27年左右可到100级。研究所越多越好,别让研究员闲着。
- [x] **文明之地**<br>单局累计毕业200学生（沙盒模式无法完成）<br>保持学校满员运转,毕业200人只是时间问题。和学无止境同一局做,学校越多越快。
- [x] **博览群书**<br>消耗1000书籍（沙盒模式无法完成）<br>书籍由印刷工坊生产,学校、书院等教育建筑会持续消耗。建2-3座印刷工坊不断产书,教育体系正常运转,累计消耗1000本自然达成;缺书就从商船买。
- [x] **学无止境**<br>超过三百人口后，保证十年内所有成年人受教育率100%（沙盒模式无法完成）<br>※需要拉尼娅势力声望5级(大学院路线)。拉尼娅到5级解锁大学院,建一座让所有成年人回炉受教育,是达成100%最省事的路;没有大学院就要靠大量学校保证每个孩子都上学。这十年里别大规模接纳没受过教育的流民。
- [x] **熟能生巧**<br>某项熟练度等级达到三级（沙盒模式无法完成）<br>工人长期固定在同一个岗位,熟练度会慢慢涨。别频繁调岗,挑一个高价值岗位(如铁匠、裁缝)让同一批人干到底,中期即可到三级。

- [x] **经商头脑**<br>任意势力声望达到5级（沙盒模式无法完成）<br>声望靠和商队交易、完成势力订单提升。挑一个势力专注交易它需求的货物,声望升得很快;这也是名震四方的第一站。

## 城市建设

- [x] **基础设施**<br>开局一年内建造好裁缝铺，铁匠铺，劈柴小屋（沙盒模式无法完成）<br>易错过!! 开局优先收集木头、石头和铁,第一年(冬末前)把裁缝铺、铁匠铺、劈柴小屋建齐。前期人手紧,把这三样的优先级提到住房之前,错过第一年这局就废了。
- [x] **道路畅通**<br>单局内建造50格的路（沙盒模式无法完成）<br>开局铺一条连接采集点与仓库的土路就够50格,还能加25%移动速度,顺手的事。
- [x] **道路规划**<br>城镇中道路类建筑共计有2000格（沙盒模式无法完成）<br>2000格约等于全城铺满路。后期把住宅区、工业区之间全部用路连起来,土路便宜,造完不用拆。
- [x] **城镇建造**<br>单局中建造过所有桥梁和道路（包含隧道）（沙盒模式无法完成）<br>把道路类建造菜单里的每种路、每种桥、隧道都至少建一格。隧道必须贴着山壁才能放,找一处山体;桥跨河建。打开建造菜单把道路分类下的条目逐个过一遍,缺哪种补哪种。
- [x] **城市中心**<br>建造一座市政厅（沙盒模式无法完成）<br>科技解锁市政厅后建一座即可,中期自然达成。
- [x] **建筑师**<br>建造40种不同类型的建筑（沙盒模式无法完成）<br>科技点得越多解锁建筑越多,各造一个,中期凑够40种。
- [x] **建筑专家**<br>解锁所有蓝图（沙盒模式无法完成）<br>蓝图主要来源是商船随机出售,少部分来自势力声望(四大势力到5级)。商船到达前存档,没刷到缺的蓝图就回档;城市详细面板能看还缺哪些。四势力声望5级必须全部达成(和名震四方一起做),蓝图书全了就跳。
- [x] **水力设施**<br>建造好所有水力加工建筑（沙盒模式无法完成）<br>水力加工建筑(水力磨坊、水力锯木厂等)要沿河建造。把科技里解锁的每一种水力建筑都造一座,建完即跳。
- [x] **住房改造**<br>拥有50个永不磨损的住房（居住的场所）（沙盒模式无法完成）<br>※需要科技"改造:结构强化"。点开后,点开住宅面板右上角的强化并选择加固,左下角显示"不可摧毁"即成功。给50座有人住的房子逐个加固,材料不够就慢慢攒;加固后的房子地震也塌不了,顺便帮建筑工、饱经风雪在地震里保平安。
- [x] **温暖住所**<br>人口100以上时，所有市民都居住在奢华住宅或花园别墅中（沙盒模式无法完成）<br>关键坑:只要场上还存在任何其他类型的住宅(普通住房、公寓、老年住宅),哪怕关闭不启用,都可能不跳成就。稳妥做法是把所有非奢华/花园别墅的住房全部拆除,只留奢华住宅和花园别墅,人口保持100以上等结算。
- [x] **大城堡**<br>所有市民居住在大城堡中（沙盒模式无法完成）<br>※需要洛伦佐势力声望5级。大城堡蓝图来自洛伦佐5级,造价极高。建议先在存档点保存,只建大城堡、关闭或拆除其他所有住宅,让全部市民入住,跳成就后读档继续,不必真的长期供养。
- [x] **建筑工**<br>保持十年没有建筑损坏（沙盒模式无法完成）<br>建筑会随时间磨损,需要建造工维修。前期保证建造工勤快,后期点出"结构强化"给关键建筑加固,加固后不再损坏,十年无损坏就稳了。
- [x] **高效供暖**<br>连续二十年不消耗生活燃料（沙盒模式无法完成）<br>※需要锅炉房科技。建锅炉房让所有住宅都进入供暖范围,住宅就不再消耗柴火等生活燃料。法令"集中供暖"给锅炉房+30%范围,方便全覆盖;每栋住宅面板上都能确认是否在供暖范围内,有漏网的赶紧补锅炉房。保持二十年全覆盖即跳。
